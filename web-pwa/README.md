# حسابي | Hesabi

**حسابي** هو تطبيق ويب عربي قابل للتثبيت (PWA) لإدارة المرحلة الأولى من تشغيل المتجر: المنتجات، حركات المخزون، المبيعات، والفواتير. يعمل التطبيق محليًا ودون خادم أو خدمات خارجية؛ فكل بيانات المتجر تحفظ في **IndexedDB** في متصفح الجهاز.

## ما الذي يغطيه الإصدار الأول؟

| المجال | ما يتوفر الآن |
|---|---|
| الإعداد | اسم المتجر، النشاط، والعملة في أول تشغيل فقط |
| المنتجات | إضافة، بحث بالاسم أو الباركود أو الكود الداخلي، تعديل، وحذف ناعم |
| المخزون | كمية افتتاحية، حالات متوفر/منخفض/نافد، وحركة تعديل موثقة |
| المبيعات | سلة، منع المخزون السالب، نقدي أو تحويل، خصم، ومبلغ مدفوع |
| الفواتير | أرقام `INV-000001` متسلسلة، تفاصيل محفوظة، وخصم مخزون ذري |
| PWA | Manifest وعامل خدمة للتشغيل بعد أول تحميل دون اتصال |

## التقنيات

التطبيق مبني بملفات واجهة الويب القياسية: **HTML5 وCSS3 وJavaScript ES Modules**. يستخدم Vite فقط كأداة بناء محلية، ويستخدم IndexedDB لتخزين `settings` و`products` و`sales` و`saleItems` و`stockMovements`، بالإضافة إلى `meta` لتسلسل الفواتير. لا توجد Firebase أو Supabase أو API خارجي أو Backend.

## التشغيل محليًا

```bash
pnpm install
pnpm dev
```

لإنتاج نسخة بناء قابلة للنشر:

```bash
pnpm build
```

ولتشغيل الاختبارات المنطقية:

```bash
node --test tests/domain.test.mjs
```

## الاستخدام

عند أول فتح، أدخل اسم المتجر ونشاطه والعملة ثم اضغط **دخول**. بعد ذلك، أضف المنتجات مع كمية افتتاحية، وعدّل الكميات من شاشة **المخزون** فقط. من **المبيعات** أضف المنتجات إلى السلة، ثم أدخل الخصم والمبلغ المدفوع وحدد وسيلة الدفع وأكد العملية. ينشئ التطبيق فاتورة وحركات بيع ويخصم الكميات ضمن معاملة IndexedDB واحدة قدر الإمكان.

## تثبيت التطبيق

افتح التطبيق من متصفح حديث. بعد أول تحميل، اختر **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية** من قائمة المتصفح. يستخدم التطبيق `manifest.json` و`service-worker.js`، وتُخزن ملفات واجهته الأساسية في التخزين المؤقت للاستخدام دون اتصال.

## الهيكل

```text
client/
  index.html
  public/
    manifest.json
    service-worker.js
  src/
    main.js
    style.css
    js/
      app.js          # العرض والتفاعلات
      constants.js    # الخيارات الثابتة
      database.js     # IndexedDB والمعاملات الذرية
      domain.js       # منطق المخزون والفواتير
tests/
  domain.test.mjs
```

## نشر GitHub Pages

يوجد إعداد GitHub Actions في المستودع الأم لنشر نسخة `web-pwa` تلقائيًا. فعّل GitHub Pages من **Settings → Pages** واختر **GitHub Actions** كمصدر للنشر. عند الدفع إلى فرع `master` بعد تعديل ملفات التطبيق، ستنشئ المهمة نسخة الإنتاج وتنشرها.

## حدود المرحلة الأولى

لا يتضمن هذا الإصدار العملاء أو الموردين أو المصروفات أو الأرباح أو الآجل أو المشتريات أو المرتجعات أو المستخدمين أو المزامنة السحابية أو التقارير المتقدمة أو النسخ الاحتياطي. هذه المجالات خارج نطاق المرحلة الحالية عمدًا.
